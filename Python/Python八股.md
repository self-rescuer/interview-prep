# Python 八股面试题

## 1. `is` 和 `==` 的区别

- `is` 判断是不是同一个对象（比较内存地址）
- `==` 判断值是不是相等

**补充：** Python 对 -5 到 256 的小整数和短字符串做了缓存，所以：

```python
a = 256
b = 256
a is b  # True

a = 1000
b = 1000
a is b  # False
```

所以比较数值时用 `==`，不要依赖 `is`。

## 2. 深拷贝和浅拷贝的区别

- **浅拷贝**：只拷贝外层对象，内部子对象是引用。修改容器里的可变子对象，原对象会跟着变。
- **深拷贝**：递归拷贝所有层级对象，完全独立。修改拷贝后的对象，原对象不受影响。

## 3. `*args` 和 `**kwargs` 的作用

- `*args`：接收不定数量的位置参数，打包成元组（tuple）
- `**kwargs`：接收不定数量的关键字参数，打包成字典（dict）

## 4. 装饰器是什么，有什么用

装饰器是在不修改原函数代码、不改变原函数调用方式的前提下，给函数增加额外功能。

**常见用途：**

- **日志**：记录函数调用
- **计时**：计算函数执行时间
- **权限校验**：比如 Django 的 `@login_required`
- **缓存**：`@functools.lru_cache`
- **测试**：Pytest 的 `@pytest.fixture`

**结合项目：** 我在 django-crm 测试里用过 `@pytest.fixture`，在接口框架里用装饰器封装了重试逻辑。

## 5. 生成器和迭代器的区别

- 普通迭代器需要手动实现 `__iter__` 和 `__next__` 两个魔术方法
- 生成器由 Python 自动实现迭代器协议，`yield` 会暂停函数并保存现场，下次 `next` 从暂停处继续执行
- 生成器惰性求值，节省内存

## 6. GIL 是什么

GIL 是 CPython 的全局解释器锁，保证同一时刻只有一个线程执行 Python 字节码。它简化了内存管理，但也导致多线程无法真正并行计算。

**影响：**

- CPU 密集型任务：多线程没用，应该用多进程
- IO 密集型任务：多线程仍然有效，因为等待时会释放 GIL

## 7. 列表推导式和生成器表达式的区别

- **列表推导式**：一次性生成完整列表，全部存入内存；支持索引、切片；数据量大时占用内存高
- **生成器表达式**：惰性求值，不会一次性创建全部元素；迭代的时候才生成，内存占用极小；不能索引
